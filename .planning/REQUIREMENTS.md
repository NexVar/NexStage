# Requirements

## Overview
GNOME Stage Manager eklentisini macOS kalitesinde goersel ve kullanilabilirlik standartlarina cikarmak.

## V1 — Must Have
These are table stakes. The product doesn't work without them.

| ID | Requirement | Phase | Status |
|----|-------------|-------|--------|
| R1 | Kapatma butonu: macOS benzeri temiz, yumusak koseli hover X butonu | 1 | Planned |
| R2 | Kart goerselleri: border-radius, box-shadow, subtle border | 1 | Planned |
| R3 | Hover animasyonlari: smooth scale, glow efekti | 1 | Planned |
| R4 | Panel arka plan: yari-saydam, blur efektli arka plan | 2 | Planned |
| R5 | Uygulama adi: tooltip veya label olarak gosterme | 2 | Planned |
| R6 | Aktif pencere vurgulama: border veya glow ile belirginlestirme | 2 | Planned |
| R7 | Sag tik context menu: Kapat, Minimize, Always-on-Top | 3 | Planned |
| R8 | Ayarlar paneli: Yeni ozellikleri toggle edecek ayarlar | 3 | Planned |

## V2 — Nice to Have

| ID | Requirement | Priority | Status |
|----|-------------|----------|--------|
| R10 | Multi-monitor: Her monitorde bagimsiz panel | High | Backlog |
| R11 | Workspace integration: Workspace bazli gruplama | Medium | Backlog |
| R12 | Tema uyumu: System theme renklerini otomatik kullanma | Medium | Backlog |
| R13 | Trackpad gestures: Uclu/dortlu swipe destegi | Low | Backlog |

## Out of Scope
- Farkli DE destegi (KDE, XFCE) — sadece GNOME
- Compositor seviyesi degisiklik — extension API sinirlarinda kalacak
- Wayland protokol eklentileri — mevcut GNOME Shell API kullanilacak
